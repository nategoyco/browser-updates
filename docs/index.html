A sidebar that tidies itself.

Pin what you use every day as big icon tiles, just by dragging a tab to the top. Everything else lives in Today, and one click on Tidy sorts it into folders by what kind of site it is.

  • Drag tabs to reorder them, drop them into folders, or pull them up to pin
  • Tabs you haven't opened in a while go to sleep and free up memory
  • Unused tabs move to the Archive, so nothing is ever lost

Spaces with their own color and logins.

Keep Work and Personal apart. Each space gets its own tabs, its own color from a soft palette or a gradient you pick, and if you like, its own cookies, so you can be signed into two accounts at once.

The bar takes on every site's color.

Pane reads each page's own color and tints the bar above it to match, with text that stays readable. The browser steps back and the page takes the whole window.

Everything else you'd expect.
A few things you wouldn't.

Built on WebKit, the engine behind Safari, so it's fast, light on battery and made for the Mac.

Ads and trackers blocked

On by default and run inside the engine, so pages load faster. Pause it for any site.

Picture in picture

Leave a tab while a video plays with sound and it floats in its own window. Muted videos and previews never pop out.

Glance

Links from Mail, Slack or a pinned Gmail open in a small window first. Keep the page with ⌘ ↩.

Split view

Two pages side by side in one window, with a divider you can drag.

Designer tools

An eyedropper that copies any color's hex, and a font inspector that shows a page's type styles.

Save anything

Right-click to Save Video, Image, Link or Page As, straight to where you want it.

Bring your stuff

Import bookmarks and history from Dia, Arc, Chrome, Safari, Brave or Edge in a click.

History, bookmarks, archive

All searchable from the tab panel, and every tab you close can come back with ⌘ ⇧ T.

Quiet updates

New versions arrive inside the app. Click Install and Relaunch and you're done.

Made for the keyboard.
